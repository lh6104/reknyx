# Fennec: architecture comparison with the CoreVAPT MVP

Source snapshot reviewed: **2026-11-02**, repository `https://github.com/Fennec-AI/Fennec`, commit **`e56c8c1c5cbeea93b719f8001ea136c6b15c7055`**. Scope: OSS checkout at `/tmp/corevapt-upstream-research/Fennec`; all source links are pinned. Historical source/Git-metadata review only: no dependency installation, upstream imports/execution, model calls, containers, scanners, or secrets. “Wired” means traced source calls, not proven runtime behavior, finding quality, or performance. English translation did not rerun this review.

**Conclusion:** borrow role separation, hypothesis queues, review, and finding presentation; do not adopt the entire execution core. Retain CoreVAPT's FastAPI/PostgreSQL/worker, bounded live Nmap/ZAP and Greenbone import, worker policy, sourced evidence, and reviewed report snapshots. Evidence-dependent next actions and basic cross-tool correlation are P0. A deterministic state machine enforces transitions/authority without requiring a fixed scanner sequence. Code and authorized human decisions own execution authority.

## 2. Six transferable patterns

### 2.1. Deterministic routing and role-specific work — P0 state machine; defer autonomous loop

`orchestrator_node` processes results and selects the next hypothesis without an LLM router. Graph connects recon → analyst and pentester → orchestrator, with additional recon requests capped at three. Graph `success` depends on findings, so it differs from successful scan completion. Recon also has its own self-loop; the additional-recon cap does not bound every loop. Sources: [src/graph/role_based_graph.py:44–177](https://github.com/Fennec-AI/Fennec/blob/e56c8c1c5cbeea93b719f8001ea136c6b15c7055/src/graph/role_based_graph.py#L44-L177), [202–280](https://github.com/Fennec-AI/Fennec/blob/e56c8c1c5cbeea93b719f8001ea136c6b15c7055/src/graph/role_based_graph.py#L202-L280).

**CoreVAPT proposal:** deterministic `queued → policy_checked → awaiting_approval → running → parsing → review_ready → reported`, plus failure/cancellation; approval only when policy requires it. Separate `execution_status`, `coverage_status`, and `finding_count`: no findings can still be successful execution, while missing data is not safety. Register Nmap/ZAP/Greenbone import explicitly; LangGraph is optional. Keep an HTTP/no-HTTP adaptive branch in P0. Defer full hypothesis trees, coding agents, and autonomous exploitation, rather than deferring all adaptive planning.

### 2.2. Contextual playbooks — P1 knowledge; P0 capability contract

Registry normalizes names, searches Markdown groups, caches content, strips frontmatter, and combines `hypothesis.skills`. `PromptBuilder` calls the helper and pentester calls `build_prompt`, so the path is wired. Sources: [src/skills/registry.py:54–107](https://github.com/Fennec-AI/Fennec/blob/e56c8c1c5cbeea93b719f8001ea136c6b15c7055/src/skills/registry.py#L54-L107), [134–177](https://github.com/Fennec-AI/Fennec/blob/e56c8c1c5cbeea93b719f8001ea136c6b15c7055/src/skills/registry.py#L134-L177), [src/prompts/builder.py:114–122](https://github.com/Fennec-AI/Fennec/blob/e56c8c1c5cbeea93b719f8001ea136c6b15c7055/src/prompts/builder.py#L114-L122), [src/agents/pentester.py:398–420](https://github.com/Fennec-AI/Fennec/blob/e56c8c1c5cbeea93b719f8001ea136c6b15c7055/src/agents/pentester.py#L398-L420).

**CoreVAPT proposal:** separate explanatory knowledge from executable capabilities. P0 capabilities declare `capability_id`, adapter/parser versions, input schema, target types, risk class, approval requirement, timeout, and output artifact types. P1 knowledge helps suggest tests/remediation. Markdown/model text cannot become arbitrary worker commands. Pin playbook versions when used in report interpretation.

### 2.3. Review snapshot and resume — P0 with execution binding

`human_review_node` constructs a hypothesis snapshot, calls `interrupt()`, and accepts approve/reject/edits; rejection removes queue items. Empty resume may count as unedited approval. HTLI uses `MemorySaver`; default graph disables review. Sources: [src/agents/human_review.py:37–115](https://github.com/Fennec-AI/Fennec/blob/e56c8c1c5cbeea93b719f8001ea136c6b15c7055/src/agents/human_review.py#L37-L115), [118–170](https://github.com/Fennec-AI/Fennec/blob/e56c8c1c5cbeea93b719f8001ea136c6b15c7055/src/agents/human_review.py#L118-L170), [src/graph/role_based_graph.py:296–305](https://github.com/Fennec-AI/Fennec/blob/e56c8c1c5cbeea93b719f8001ea136c6b15c7055/src/graph/role_based_graph.py#L296-L305).

**CoreVAPT proposal:** immutable PostgreSQL approvals record actor/time/decision, scope revision, capability/version, scan config, and plan hash. Recheck before execution; changed target/config requires new approval. Greenbone import validates file/provenance without granting live execution rights. Risk-class policy governs the gate; hypothesis review cannot replace pre-network approval. Acceptance: restart while pending, repeated submission, and scope changes after grant.

### 2.4. Layered finding presentation — P0 evidence/basic correlation

Schema separates description, impact, request/response, and remediation, but rich fields are optional; validators mainly normalize nested JSON strings. Pentester adds an LLM gap-filler and dashboard flattening. Sources: [src/schemas/pentester_result.py:89–157](https://github.com/Fennec-AI/Fennec/blob/e56c8c1c5cbeea93b719f8001ea136c6b15c7055/src/schemas/pentester_result.py#L89-L157), [160–207](https://github.com/Fennec-AI/Fennec/blob/e56c8c1c5cbeea93b719f8001ea136c6b15c7055/src/schemas/pentester_result.py#L160-L207), [src/agents/pentester.py:218–295](https://github.com/Fennec-AI/Fennec/blob/e56c8c1c5cbeea93b719f8001ea136c6b15c7055/src/agents/pentester.py#L218-L295), [572–601](https://github.com/Fennec-AI/Fennec/blob/e56c8c1c5cbeea93b719f8001ea136c6b15c7055/src/agents/pentester.py#L572-L601).

`Finding` includes status/location/evidence/hypothesis links and `CorrelationStore` holds dictionaries/relationships. Yet pending-result handling creates findings from strings, sets `location=hyp.title`, and assigns `CONFIRMED`. A correlation data type does not demonstrate automatic cross-scanner matching. Sources: [src/state/correlation.py:18–71](https://github.com/Fennec-AI/Fennec/blob/e56c8c1c5cbeea93b719f8001ea136c6b15c7055/src/state/correlation.py#L18-L71), [97–163](https://github.com/Fennec-AI/Fennec/blob/e56c8c1c5cbeea93b719f8001ea136c6b15c7055/src/state/correlation.py#L97-L163), [src/agents/analyst.py:309–329](https://github.com/Fennec-AI/Fennec/blob/e56c8c1c5cbeea93b719f8001ea136c6b15c7055/src/agents/analyst.py#L309-L329).

**CoreVAPT proposal:** separate scanner observations, normalized findings, and review decisions. P0 evidence references artifact/hash, run/source, scanner/parser versions, acquisition time, and raw locator; model text cannot replace it. Severity and validation are separate. Render PDF from reviewed snapshots. Basic deduplication/correlation uses asset/service/location and declared rule equivalence, retaining all observations; never merge solely by CVE/title. Defer advanced mappings and do not raise validation from model agreement alone.

### 2.5. REST snapshots and progress events — P0 plus durable audit

`Job` keeps results/tool calls/tasks/review queues in process-local dictionaries; API launches `asyncio.create_task`. Publisher fans out to queues and removes full subscribers. Frontend opens `EventSource`, handles event types, and closes on error. Sources: [src/api/job_store.py:23–61](https://github.com/Fennec-AI/Fennec/blob/e56c8c1c5cbeea93b719f8001ea136c6b15c7055/src/api/job_store.py#L23-L61), [131–155](https://github.com/Fennec-AI/Fennec/blob/e56c8c1c5cbeea93b719f8001ea136c6b15c7055/src/api/job_store.py#L131-L155), [src/api/server.py:380–397](https://github.com/Fennec-AI/Fennec/blob/e56c8c1c5cbeea93b719f8001ea136c6b15c7055/src/api/server.py#L380-L397), [src/api/events.py:28–50](https://github.com/Fennec-AI/Fennec/blob/e56c8c1c5cbeea93b719f8001ea136c6b15c7055/src/api/events.py#L28-L50), [frontend/src/hooks/usePentestStream.ts:572–624](https://github.com/Fennec-AI/Fennec/blob/e56c8c1c5cbeea93b719f8001ea136c6b15c7055/frontend/src/hooks/usePentestStream.ts#L572-L624).

**CoreVAPT proposal:** REST reads authoritative PostgreSQL state; SSE is a display channel. Worker uses transactional claim/lease/heartbeat and controlled transitions. Sequential event IDs let clients detect gaps and reload snapshots. Persist approval/execution audit before emission. P0 polling reduces implementation work; a separate broker is optional. Acceptance: kill worker, reconnect client, retry job, and check unintended duplicate execution.

### 2.6. Central execution adapter and resource limits — P0; defer arbitrary shell

Terminal centralizes Docker/local execution and timeout/output limits; local uses subprocess shell and Docker wraps shell commands. Reviewed paths show no target allowlist/action approval. Browser uses `httpx` directly in Python, so not all network traffic is necessarily inside Kali. Docker bridge, `NET_RAW`, CPU/RAM limits are not scope enforcement. Sources: [src/tools/execution.py:18–91](https://github.com/Fennec-AI/Fennec/blob/e56c8c1c5cbeea93b719f8001ea136c6b15c7055/src/tools/execution.py#L18-L91), [178–209](https://github.com/Fennec-AI/Fennec/blob/e56c8c1c5cbeea93b719f8001ea136c6b15c7055/src/tools/execution.py#L178-L209), [src/docker/client.py:14–24](https://github.com/Fennec-AI/Fennec/blob/e56c8c1c5cbeea93b719f8001ea136c6b15c7055/src/docker/client.py#L14-L24), [50–80](https://github.com/Fennec-AI/Fennec/blob/e56c8c1c5cbeea93b719f8001ea136c6b15c7055/src/docker/client.py#L50-L80).

**CoreVAPT proposal:** adapters accept typed config and build argv or controlled scanner API calls, never user/model shell strings. Policy enforces destination, DNS/redirect boundaries, and approval before dispatch. Bound timeout, cancellation, and resources; retain exit/parser/truncation states separately. Store full artifacts within quota; a truncated preview cannot be the sole evidence. Exclude terminal, arbitrary file writing, and coding-agent execution from the MVP.

## 3. Counterpatterns to prevent

- **Expected artifacts treated as actual:** on vulnerable results the manager inserts `expected_outputs` into the registry and `actual_outputs` without collector evidence. CoreVAPT artifacts exist only after successful collection/hash checks. Source: [src/orchestration/hypothesis_manager.py:178–211](https://github.com/Fennec-AI/Fennec/blob/e56c8c1c5cbeea93b719f8001ea136c6b15c7055/src/orchestration/hypothesis_manager.py#L178-L211).
- **Prompt text treated as authority:** authorization prompts assume external permission and ask the model to obey boundaries; this is not code enforcement. Source: [src/prompts/sections/authorization.py:9–31](https://github.com/Fennec-AI/Fennec/blob/e56c8c1c5cbeea93b719f8001ea136c6b15c7055/src/prompts/sections/authorization.py#L9-L31).
- **Review without durable history:** history endpoint returns an empty list and submission sends edits to a queue. Create-job accepts target URLs with HTLI false by default; reviewed paths show no authentication dependency or verified-target check. Per-job configuration is moved through process-global environment, creating a potential concurrent configuration-mixing risk. Sources: [src/api/server.py:109–119](https://github.com/Fennec-AI/Fennec/blob/e56c8c1c5cbeea93b719f8001ea136c6b15c7055/src/api/server.py#L109-L119), [191–203](https://github.com/Fennec-AI/Fennec/blob/e56c8c1c5cbeea93b719f8001ea136c6b15c7055/src/api/server.py#L191-L203), [554–560](https://github.com/Fennec-AI/Fennec/blob/e56c8c1c5cbeea93b719f8001ea136c6b15c7055/src/api/server.py#L554-L560), [584–612](https://github.com/Fennec-AI/Fennec/blob/e56c8c1c5cbeea93b719f8001ea136c6b15c7055/src/api/server.py#L584-L612). These are static observations/inferences, not reproduced exploits.
- **Model budget confused with scanner safety:** `balanced` configures model calls, timeout, and recursion, not scan rate/intensity/allowlists. CoreVAPT needs independent profile policy. Source: [src/config/settings.py:130–157](https://github.com/Fennec-AI/Fennec/blob/e56c8c1c5cbeea93b719f8001ea136c6b15c7055/src/config/settings.py#L130-L157).

## 4. Export, licensing, and limits

CLI generator writes summaries, per-agent reports, vulnerability Markdown, and raw-events JSON; the CLI selects this path only in legacy mode. Generator existence does not prove default CLI/API artifact production. Sources: [cli/main.py:83–89](https://github.com/Fennec-AI/Fennec/blob/e56c8c1c5cbeea93b719f8001ea136c6b15c7055/cli/main.py#L83-L89), [138–175](https://github.com/Fennec-AI/Fennec/blob/e56c8c1c5cbeea93b719f8001ea136c6b15c7055/cli/main.py#L138-L175), [221–227](https://github.com/Fennec-AI/Fennec/blob/e56c8c1c5cbeea93b719f8001ea136c6b15c7055/cli/main.py#L221-L227), [493–518](https://github.com/Fennec-AI/Fennec/blob/e56c8c1c5cbeea93b719f8001ea136c6b15c7055/cli/main.py#L493-L518). CoreVAPT needs its own versioned snapshot-to-PDF implementation, report hashes, and review status. LLM-filled narrative must not become original evidence.
