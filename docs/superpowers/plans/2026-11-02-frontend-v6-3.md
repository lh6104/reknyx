**Architecture:** Preserve standalone V6.2 domain state/guards/fixtures in a new V6.3 HTML. Replace view composition and add derived dashboard selectors and session-only defaults. Reuse existing approval/evidence/review/snapshot logic; no new backend contracts or framework.

**Tech Stack:** HTML/CSS/JavaScript; environment-provided Node/Playwright for verification.

**Spec:** [UX standards, page map, settings and demo scenarios](../../research/UX_STANDARDS_AND_PAGE_MAP.md).

## Constraints

- Preserve V6.1/V6.2 byte for byte; V6.3 opens locally and starts on Dashboard.
- Documentation and product labels are English; explanatory handoff to the user is Vietnamese.
- No backend/scanner/model calls, native parser claims, paid API calls or publication.
- Two permanent primary destinations; three contextual assessment views; one overlay at a time.
- Defaults apply to new assessments only; current scope/approval require explicit revision/review.
